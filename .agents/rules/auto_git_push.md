# Auto Git Push Rule

دائماً وبعد الانتهاء من أي تعديل على الكود وحفظ الملفات في أي مهمة:
1. قم مباشرة بعمل `git add` للملفات المعدلة.
2. قم بعمل `git commit` مع رسالة وصفية واضحة للتعديل باللغة المناسبة.
3. قم بعمل `git push origin main` فوراً دون انتظار إذن أو طلب منفصل من المستخدم.
4. أبلغ المستخدم فور اكتمال الرفع بنجاح.
